Mis Proyectos ASIR

Administración de Sistemas, Linux, Redes, Seguridad y Monitorización

1. Distribución propia basada en Arch Linux

Creación de una distribución Linux personalizada partiendo de la imagen base de Arch Linux. El proyecto abarcó desde la configuración inicial del sistema (particiones, red, usuarios, kernel) hasta la personalización del entorno gráfico y la generación de una imagen ISO arrancable. Este proceso me permitió comprender a fondo la arquitectura de un sistema operativo Linux y cómo sus diferentes componentes interactúan entre sí desde una base mínima.

2. Honeypot SSH con Cowrie y Pila ELK

Implementación de un honeypot SSH utilizando Cowrie integrado con la pila ELK (Elasticsearch, Logstash, Kibana) dentro de una infraestructura aislada. El objetivo principal fue simular un servidor vulnerable para registrar, transformar y almacenar intentos de acceso y comandos maliciosos. Finalmente, utilicé Kibana para crear dashboards visuales, permitiendo analizar de forma intuitiva los logs de seguridad y la monitorización de posibles atacantes.
